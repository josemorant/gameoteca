# Documentation images

The SVG banner is original Gameoteca artwork by Jose Morant, released under MIT. It uses the project's red/white identity and original game-case and scanner illustrations.

The PNG files are unaltered browser captures of the real application in English. They were captured using a temporary copy of an author-provided collection, with personal notes cleared in that copy. The original database was not changed. The mobile image uses a 390 × 844 responsive viewport and shows the scanner before camera activation; it is not a claim of a completed physical-phone camera test.

No pairing PIN, QR code, network address, private certificate or database is included. Game covers are visible only as part of the application's documented interface; their rights remain with their respective holders.
