# Gameoteca icon

Author: Jose Morant. Original project artwork is released under MIT.

The icon was generated with ImageGen. The original master is public/icons/gameoteca-master.png; scripts/export-icons.py exports PNG and ICO variants using Pillow, preserving transparency and design.

Original white G lettering sits inside a red (#e60012) rounded square with transparent outer corners. The interface uses original SVG symbols in public/ui-icons.svg.

- Favicon: public/icons/favicon.ico.
- PNG sizes: 16, 32, 48, 180 (Apple), 192, 256 and 512 pixels.
- Windows: build/gameoteca.ico, containing sizes from 16 to 256 pixels.
- Web manifest: public/site.webmanifest; defines names, colors and icons, without offline support.
- Electron uses these assets for its window, executable and installer icons.
